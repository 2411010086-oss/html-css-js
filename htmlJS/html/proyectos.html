Mis Proyectos

Automóvil

Proyecto presentado en la feria de exposiciones en la Universidad Nacional de Cañete. Consistía en utilizar un aplicativo móvil para hacer mover a un automóvil pequeño a través de conexiones con arduino.

Página Web

Página Web desarrollada en PRO a la educación, donde utilizando las librerias de tailwind, utilicé información de una institución educativa para llamar a más estudiantes a participar de la misma, llamando más su atención.

Desarrollo Web

Una de las primeras páginas que desarrollé en este camino de desarrollador Web, utilizando HTML y CSS aprendí a agregar el responsive a mis páginas para que tengan un diseño más coherente al momento de cambiar el tamaño de página.
